Graduate and undergraduate research, Missouri State University

Jan 2021 – May 2026
  • GenMOR: generative models for multi-objective planning Can a generative model learn what makes a plan Pareto-optimal just from data? Work in progress.

    GenMOR is a generative learning framework that extends the MORNP-DEC multi-objective planning problem. I train plain autoencoder and variational autoencoder (VAE) architectures on synthetically generated, structured plan vectors to learn latent representations, generate new candidate plans, and test whether generative models can implicitly capture Pareto dominance from data.

    • Generative models
    • VAEs
    • Multi-objective planning
  • Question answering that knows when not to answer BERT fine-tuned on SQuAD 2.0 with an answerability classifier and calibrated confidence scores.

    A calibration-aware extractive QA system: BERT fine-tuned on SQuAD 2.0, augmented with an answerability classifier and a confidence-scoring component. The model is trained to predict answer spans while learning to abstain from unanswerable questions, and to produce confidence scores that genuinely reflect how likely an answer is to be correct.

    • NLP
    • BERT
    • Calibration
  • Meta-ensemble explainable AI A framework that learns to combine LIME, SHAP and Grad-CAM into more reliable visual explanations.

    Instead of trusting a single explanation method, this framework integrates several (LIME, SHAP and Grad-CAM) and learns how to combine them into one visual attribution. It showed improved fidelity, stability and sparsity compared with each method on its own.

    • Explainable AI
    • LIME
    • SHAP
    • Grad-CAM
  • Spam classification across datasets Generative vs. discriminative models on SMS and email spam, including a Naive Bayes classifier built from scratch.

    A pipeline comparing generative and discriminative models, including a custom multinomial Naive Bayes implementation, on the SMS Spam Collection (5,574 messages) and a large Enron-style email corpus (421,796 messages), with chi-square and mutual-information feature selection.

    Linear SVM performed best on SMS (F1 0.947), while the custom Naive Bayes slightly outperformed the discriminative baselines on email (F1 0.988). Aggressive univariate feature pruning substantially hurt recall for generative models while giving discriminative models only marginal efficiency gains.

    • NLP
    • Data science
    • Naive Bayes
    • SVM
  • Real-time eye-tracking analytics A consent-first system that turns gaze data into engagement maps for web design.

    User interactions were captured with HTML and JavaScript behind fully compliant consent management. A Python and Flask backend processed over 1,000 gaze data points per session into line-of-sight engagement maps, and design changes based on those maps increased user engagement by 15%.

    • Data science

Projects

GenMOR

Current project, manuscript in preparation

When a plan has to balance several goals at once, there is rarely a single best answer. Instead there is a set of trade-offs, the Pareto front, where improving one goal means giving up another.

GenMOR trains autoencoders and variational autoencoders on structured plan vectors to learn compact representations of plans, generate new candidate plans, and test whether a generative model can pick up Pareto dominance from data alone.

A full write-up is coming soon.

Autonomous surface vessels

AIG Lab, Missouri State University, 2024

Maritime simulation environments built in Panda3D to test how autonomous surface vessels navigate head-on, crossing, overtaking, multi-vessel and traffic-separation-scheme scenarios.

I implemented and compared Velocity Obstacle, Rapidly-exploring Random Tree (RRT) and hybrid VO-RRT-COLREGs path planners, classifying each encounter and choosing the avoidance maneuver that COLREGs, the international rules for avoiding collisions at sea, require.

A full write-up is coming soon.
